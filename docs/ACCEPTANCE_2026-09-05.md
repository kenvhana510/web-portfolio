## 3. 修正した欠陥

### 事実性（公開すると問題になるもの）— 4件、すべて解消
1. H1「WordPressサイトを、30,000円から。」— 30,000円は PLAN A(LP) の下限で WordPress は 150,000円〜。同一画面の料金行と矛盾
2. 「WordPress（SWELL）を中心に制作した6作品」— 実際は WordPress 2件 / 静的HTML 4件（`works.html` の同じ誤りも修正）
3. PRICE の「対応しないこと」が `service.html` の正本より項目落ち。修正回数も欠落
4. 最終CTAの「プラットフォーム経由でお問い合わせください」— 実際は3項目の直フォーム（`about.html` の FLOW 01 も同様）

### 実画面を見なければ検出できなかったもの — 5件、すべて解消
1. **作品6件が透明のまま表示されなかった**（後から差し込んだ `.reveal` が監視対象に入っていなかった）
2. **開示文「架空のクライアントを想定した自主制作」が画像に覆われて読めなかった**
3. **作品カードの偶数番だけ画像が3割小さい**（441px → 292px）
4. **作品画像にブラウザのスクロールバーが焼き込まれていた**（6サイト撮り直し）
5. 見積ツールに、常時非表示のボタンを説明する注記だけが表示されていた

### 自分で見つけた計測の後退 — 1件、解消
`proto-works.js` が `MEASUREMENT_SPEC` 2.3 の `data-work-id` 等を落としており、
作品別トラッキングが GA4 に届かなくなっていた。画面上は正常に見えるため気づけない種類の欠陥。

### その他
CTA階層の逆転（Primary が Secondary より小さい／料金直後に相談導線が無い）、
ラベルの不統一（4箇所で3種類）、H1 の語中改行、320px でのロゴとCTAの接触、
「選ばれる理由」左カラムの 600px 空白、本文に「ホームページ制作」が一度も無かった問題、
`about.html` の「プロフィール写真準備中」プレースホルダ。

## 5. Design System の正規化について（§17）

**共通化は行っていない。** `proto-top.css` と `proto-aichi.css` で
ヘッダー常設CTA・本文16px・タップ標的のルールが重複している。

理由: 消費者が2つしかなく、重複は約40行。共通ファイルへ切り出すと
**検証済みの TOP を作り直して再計測する必要があり、そのコストの方が大きい**
（Reuse Benefit < Abstraction Cost）。

**切り出す条件**: 3つ目の消費者が現れた時点。そのとき抽出する候補は以下。

| 候補 | 現在の重複箇所 | 抽出の価値 |
|---|---|---|
| 追従ヘッダーの常設CTA | proto-top / proto-aichi | 高（判断が同一） |
| 本文 16px / 行間 1.75 | 同上 | 高 |
| タップ標的 24px / 44px | 同上 | 高 |
| 明転サーフェス（Ivory 地 + 明地専用の金） | proto-top のみ | 中（2つ目が出たら） |
| 料金カード | proto-top のみ | 中 |
| FAQ アコーディオン | proto-top のみ | 中 |
| 実物ショット（PC+SP の組） | proto-top / proto-aichi（主従が逆） | 低（意図的に別物） |

**インラインスタイルの削減**は行わない（PHASE 19 で結論）。
実測すると全11ページで **28属性 / 31宣言のみ**で、`index.html` と両ツールは 0件だった。
`AUDIT_2026-09-05.md` P7 の「inline style でレイアウトしている負債」という見立ては
**規模を過大に見積もっていた**ので撤回する。実害は `case-study.html` の1件のみで、
それは修正済み（`padding:3rem 0` が `.container` の左右 padding を潰していた）。
詳細は `PHASE19_PRE_PRODUCTION_2026-09-05.md` §3。
