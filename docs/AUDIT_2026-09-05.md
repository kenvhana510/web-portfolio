# LEGACRAFT 公式サイト CURRENT STATE AUDIT

計測日: 2026-09-05 / 対象: 本番 https://legacraft.jp/（6ページ × Desktop 1440 / Mobile 390）
計測方法: Playwright + Chromium 実描画。LCP / CLS は PerformanceObserver 実測、
コントラストは背景をアルファ合成した上で WCAG 2.1 の式で算出。
生データ: `audit.json` / `contrast.json`（scratchpad、リポジトリ外）

Task OS 上の Continuous Commitment「LEGACRAFT公式サイト改装」の Next Action=現状監査 に対応する。

## 0. 結論

**壊れているサイトではない。作り込みが止まっているサイトである。**

技術品質（性能・アクセシビリティ・実装）は既に高い水準にある。
一方で **トップページが「Conversionを取る構造」になっていない**。
最大の損失は見た目でも速度でもなく、**スクロールの大半にCTAが存在しないこと**。

/aichi/ だけが Problem→Approach→Works→Price→Area→Flow→FAQ→CTA という
成約構造を持っており、トップページはその構造を持っていない。
つまり **一番流入するページが一番弱い**。

## 2. ACCESSIBILITY — ほぼクリーン（1件のみ実在、修正済み）

### 検出された唯一の AA 違反（本監査で修正済み）
| 対象 | 実測比 | 要件 | 状態 |
|---|---|---|---|
| `.contact-form-req`（必須バッジ, 10.9px/700） | 4.09 | 4.5 | 修正済 |
| `.contact-status.is-live`（対応中バッジ, 11.5px/700） | 4.09 | 4.5 | 修正済 |
| `.contact-form-success`（送信後メッセージ） | 4.09※ | 4.5 | 修正済 |

修正後、**6ページ×2ビューポート＝12通りすべてで違反 0** をローカル実測で確認。

※ `.contact-form-success` は送信後にしか描画されないため自動計測には現れないが、

## 3. CONVERSION — ここが本丸

### 3.1 CTA空白帯（最大の問題）

CTAのページ内Y座標を実測した結果：

| ページ | ビューポート | ページ全高 | ページ内CTAのY | 最大空白 |
|---|---|---|---|---|
| **/ (TOP)** | Mobile | 7,340px | 554 → 6,875 | **6,321px（全体の86%）** |
| **/ (TOP)** | Desktop | 8,424px | 636 → 8,069 | **7,433px** |
| /aichi/ | Mobile | 8,346px | 412, 482 → 5,092 → 8,022 | 4,610px |
| /service.html | Mobile | 4,088px | 2,614, 2,687 → 3,818 | 2,614px |

トップページは Hero を過ぎた瞬間から最後の CTA まで、
**モバイルで6,300px以上、行動できる場所が一つもない**。
WORKS・VALUE・FLOW という「一番説得している区間」に受け皿がない。

**サイト全体に sticky / floating CTA が存在しない。**

### 3.2 トップページに無いもの

| 要素 | TOP | /aichi/ |
|---|---|---|
| Problem（課題提示） | ✗ | ✓ |
| Price（料金） | ✗ | ✓ |
| Area（対応エリア） | ✗ | ✓ |
| FAQ | ✗ | ✓ |
| Proof（自主制作である旨の開示） | ✗ | ✓ |

料金は本サイトの最大の差別化点（「料金と対応しないことを先に出す」）なのに、
**トップページには金額が一切書かれていない**。

### 3.3 /aichi/ の主張と実物の不一致

/aichi/ には H2「制作物は、中身をすべて公開しています」という見出しがあるが、
**このページに載っている画像は 32px と 24px のロゴ2点だけで、作品画像は0枚**。
成約を取りにいくページで、最も強い証拠（実物の見た目）が視覚として存在しない。

### 3.4 Offer の伝わり方

Hero の H1 は「未来へ、遺す。」。ブランドとしては強いが**オファーではない**。
何を・いくらで・誰にがサブコピー4〜6行に押し込まれている。
`/aichi/` の Hero はオファー段落＋CTA＋価格を出しており、こちらが正しい形をしている。
