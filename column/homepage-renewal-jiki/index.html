ホームページのリニューアル時期は、「スマホで崩れる」「情報が古い」「更新できる人がいない」のどれかに当てはまったら、もう来ています。「作ってから○年」という年数より、今のサイトが仕事をしているかで判断します。この記事では、リニューアルの6つのサイン、作り直しでやること、費用の考え方を順番に説明します。

結論：年数ではなく「サイン」で判断する

「5年たったからリニューアル」と言われることもありますが、年数そのものは目安にすぎません。大事なのは、今のサイトがお客さんの役に立っているかです。

次の6つのうち、2つ以上当てはまるなら、リニューアルを考える時期です。

リニューアルを考える6つのサイン

1. スマホで見ると崩れる

今、ホームページを見る人の多くはスマホからです。パソコン用のまま放置されたサイトは、文字が小さく、横にはみ出し、ボタンが押しにくい。それだけで「ここは古い会社かも」と思われます。

2. 情報が古い

営業時間が変わっている、やめたサービスが載っている、代表の名前が前のまま。こうした「小さなウソ」は、信頼を少しずつ減らします。

3. 更新できる人がいない

「作った業者さんと連絡が取れない」「ログインの仕方が分からない」。これは本当に多いです。更新できないサイトは、情報が古くなる一方です。

4. デザインが時代遅れ

デザインの流行は変わります。細かい話は抜きにして、自分で見て「ちょっと恥ずかしい」と感じたら、お客さんも同じように感じています。

5. 問い合わせが来ない

サイトはあるのに、ここ1年で問い合わせがゼロ。原因はいろいろですが、「どこに連絡すればいいか分かりにくい」「何屋さんか伝わっていない」ことが多いです。

6. 鍵マーク（SSL）がない

ブラウザのアドレス欄に「保護されていない通信」と出るサイトです。お問い合わせフォームに名前や電話番号を入れるのが、お客さんは不安になります。

リニューアルでやること4つ

「作り直す」と決めたら、やることはこの4つです。順番も大事です。

1. 目的をひとつに絞る

「問い合わせを増やしたい」「採用に使いたい」「名刺代わりでいい」。目的によって、作るページも書く内容も変わります。まず1つに決めると、あとがぜんぶ楽になります。

2. 残す内容と捨てる内容を分ける

今のサイトの文章や写真を、「残す」「書き直す」「捨てる」に仕分けします。目安はこんな感じです。

内容どうする
会社の基本情報・沿革残す（最新に直す）
サービス説明書き直す（今の言葉で）
古いお知らせ・終了したキャンペーン捨てる
画質の悪い写真捨てて撮り直す

3. 写真を撮り直す

リニューアルでいちばん効果が出やすいのが写真です。スマホで十分なので、明るい時間に、今の店・今のスタッフ・今の現場を撮り直してください。コツはスマホ写真の記事にまとめています。

4. URL（住所）を引き継ぐ

今使っているドメイン（○○.jp など）は、できるだけそのまま使います。名刺やチラシに印刷してあるし、Googleに覚えてもらった分も引き継げるからです。ページのURLが変わる場合は、古いURLから新しいURLへ自動で飛ぶ設定（転送設定）をしておくと安心です。

リニューアルの費用はどう考える？

リニューアルの費用は、一般的には新規で作るのと大きくは変わらない、と言われます。「直すだけだから安い」とはならないことが多いです。古いサイトの中身を整理する手間が、むしろ増えることもあります。

考え方としては、次の3つを見てください。

  • 初期費用はいくらか（一括で払うのか、0円なのか）
  • 公開後の更新は誰がやるのか、いくらかかるのか
  • また数年後に同じことをくり返さずにすむか

3つ目が特に大事です。「更新できる人がいない」状態をくり返すと、何年かごとにまた作り直しです。

うちの場合は、リニューアルも新規も同じ条件です。制作費0円、月額2,980円（税込）、24ヶ月契約。今のドメインはそのまま引き継げます。公開後の更新・修正は回数無制限で、WordPressなので自分でも直せます。詳しくは料金ページと制作例をご覧ください。

リニューアル前に用意しておくと早いもの

準備があると、公開までがぐっと早くなります。

  1. 今のサイトのログイン情報（分からなければ「分からない」でOK）
  2. ドメインの契約先（どこで取ったか）
  3. 新しく撮った写真（スマホで可）
  4. 変えたい点・残したい点のメモ

うちでは、素材がそろってから14日間で公開しています。流れは公開までの流れでくわしく書いています。

まとめ

  • リニューアルは年数より「サイン」で判断する
  • スマホで崩れる・情報が古い・更新できない、は要注意
  • やることは、目的を絞る・仕分け・写真の撮り直し・URL引き継ぎ
  • 費用は新規と大きく変わらないことが多い。更新体制まで考える
  • 「また数年後に作り直し」にならない形を選ぶ
