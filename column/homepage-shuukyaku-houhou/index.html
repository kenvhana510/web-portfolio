ホームページは、作っただけでは人が来ません。山奥にお店を建てても、道が無ければだれもたどり着けないのと同じです。大事なのは、ホームページへの「入り口」を作ることです。この記事では、小さな会社ができる集客の入り口を6つ、お金をかけない順に紹介します。

ホームページは「作っただけ」では人が来ない

ホームページを公開しても、最初はほとんどだれにも知られていません。インターネットには、数えきれないほどのページがあるからです。

だからこそ、「どこからお客様に来てもらうか」を考える必要があります。入り口が多いほど、見てもらえるチャンスが増えます。

まずは全体を見てみましょう。

入り口お金ひとことで
1. 既存客の紹介ほぼかからないいまのお客様から広げる
2. Googleビジネスプロフィール無料で始められる地図検索に出る
3. 検索（SEO）手間はかかる、お金は少なめGoogleの検索に出る
4. SNS無料で始められるふだんの様子を見せる
5. 名刺・チラシ印刷代会った人をホームページへ
6. 広告広告費お金で早く人を呼ぶ

お金をかけずにできる入り口

1. 既存客の紹介

いちばん身近な入り口は、いまのお客様です。紹介された人は、ほぼ必ず会社の名前で検索します。

そのときにホームページがあれば、安心して問い合わせてもらえます。「よかったらホームページも見てください」と一言そえるだけでOKです。

2. Googleビジネスプロフィール

Googleの地図や検索に、お店や会社の情報を出せる無料の仕組みです。「地域名＋業種」で探す人に見つけてもらいやすくなります。

営業時間や写真を整えて、ホームページのアドレスを登録しましょう。くわしくはGoogleビジネスプロフィールとホームページの関係で解説しています。

3. 検索（SEO）

SEOとは、Googleの検索で上のほうに出るための工夫です。お客様が探す言葉を、ページの中にきちんと書くのが基本です。

すぐに結果は出ませんが、育てるほど長く効きます。始め方はホームページのSEO基本5つにまとめています。

ポイント：まずは「紹介」「地図」「検索」。どれもお金はほとんどかかりません。

少しの手間・費用でできる入り口

4. SNS

インスタグラムなどのSNSは、ふだんの仕事の様子を見せるのに向いています。プロフィール欄にホームページのアドレスをのせておきましょう。

SNSで興味を持った人が、ホームページでくわしく確かめる、という流れが作れます。つなぎ方はインスタとホームページの連携を参考にしてください。

5. 名刺・チラシ

会った人や、近所の人に知ってもらう入り口です。名刺やチラシにQRコードをのせれば、スマホですぐホームページを開いてもらえます。

名刺の工夫は名刺にホームページのQRコードを入れる、チラシとの使い分けはホームページとチラシの使い分けで紹介しています。

6. 広告

ネット広告は、お金をかけて早く人を呼ぶ方法です。地域や年齢をしぼって出せるものもあります。

ただ、ホームページの中身が整っていないと、広告費がもったいなくなります。広告は、ほかの入り口を整えたあとで考えるのがおすすめです。

入り口を作る前に、ホームページの中身を整える

人が来ても、知りたいことが書いていなければ帰ってしまいます。集客の前に、次の点を確認しましょう。

  1. 何をしている会社か、ひと目でわかるか
  2. スマホで見やすいか
  3. 料金や流れの目安がのっているか
  4. 問い合わせ方法がすぐ見つかるか

よくある勘違い：全部を一度にやろうとする

6つの入り口を、いっぺんに始める必要はありません。全部に手を出すと、どれも中途半端になりがちです。まずは1つか2つにしぼって、続けられる形を作りましょう。

たとえば、地域のお客様が中心の美容室や整体院なら、Googleビジネスプロフィールから。紹介が多い工務店や士業なら、紹介された人が見て安心できるホームページ作りから。業種や今のお客様の来かたで、始める順番は変わります。

今日からできること

  1. いまのお客様に「どこでうちを知ったか」を聞いてみる
  2. 自分の会社名で検索して、何が出てくるか見る
  3. 名刺にホームページのアドレスかQRコードがあるか確認する

お金をかけずに、今日からできることばかりです。

問い合わせを増やすコツはホームページの問い合わせを増やす方法でくわしく解説しています。

うちの場合、月額2,980円（税込）の中に、基本SEO設定、Googleマップ・SNSリンク、公開後の更新・修正（回数無制限）がふくまれています。集客の入り口に合わせて、ページを直していけます。

まとめ
