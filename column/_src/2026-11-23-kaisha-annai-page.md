会社案内ページは、「この会社に頼んで大丈夫かな？」と確かめに来る人のためのページです。社名や所在地などの基本項目をきちんと載せることが、まず信用につながります。そこに代表の顔写真や、この仕事をしている理由を加えると、ぐっと安心感が増します。この記事では、載せる項目と書き方のコツを紹介します。

## 会社案内ページは「確かめに来る人」のためのページ

お客様は、問い合わせる前に会社案内ページを見にきます。知りたいのは、次のようなことです。

- ちゃんと実在する会社か
- どこにあって、どのあたりまで来てくれるか
- どんな人がやっているか

つまり会社案内ページは、「怪しくないですよ」と伝えるページです。おしゃれさより、**分かりやすさと正確さ**が大事です。

ホームページ全体の中での位置づけは、[ホームページの5ページ構成](/column/homepage-5page-kousei/)でも説明しています。

## 会社概要に載せる基本項目

まずは、表でまとめる基本項目です。分かるものから埋めていきましょう。

| 項目 | 書き方のポイント |
|---|---|
| 社名・屋号 | 正式な名前。読みにくい字はふりがなも |
| 代表者 | 役職と名前 |
| 所在地 | 郵便番号から。建物名・階数まで |
| 連絡先 | 電話番号、メール、営業時間・定休日 |
| 設立・創業 | 年だけでもOK |
| 事業内容 | 何をしている会社か、箇条書きで |
| 対応エリア | 「〇〇市・〇〇市ほか」など具体的に |
| 許認可・資格 | 業種に必要な許可や、持っている資格 |
| 地図 | Googleマップを入れると迷わない |

個人事業主なら、「屋号」と「代表 〇〇」で十分です。自宅が事務所でくわしい住所を出したくない場合は、市区町村までにする方法もあります。

### 具体例：ひとりで営む個人事業主の場合

ひとりで仕事をしている場合は、項目が少なくても問題ありません。たとえば、次のように書けば十分に伝わります。

- 屋号：〇〇工房
- 代表：〇〇 〇〇
- 所在地：愛知県〇〇市（訪問・出張で対応）
- 連絡先：電話番号、営業時間 9時〜18時、日曜定休
- 事業内容：住まいの小さな修理、網戸・ふすまの張りかえ
- 対応エリア：〇〇市・〇〇市・〇〇町

「設立年」や「資本金」がなくても、信用が下がることはありません。大事なのは、空欄や「準備中」を残さないことです。書けない項目は、思いきって消してしまいましょう。

### よくある勘違い：立派に見せたほうがいい

小さな会社ほど、大きく見せようとしがちです。でも、お客様が知りたいのは「誰が来てくれるのか」です。

「スタッフ多数」と書くより、「代表とスタッフ2名で対応します」と正直に書くほうが安心されます。実際に会ったときに印象がちがうと、かえって信用を失います。

### 加えると安心感が増す項目

- **代表あいさつ**：どんな想いで仕事をしているか
- **沿革**：いつ始めて、どう歩んできたか
- **スタッフ紹介**：顔と名前が分かると話しかけやすい

うちの場合は、会社案内ページも5ページ程度の制作にふくまれています。Googleマップの埋め込みも月額2,980円（税込）の中で対応し、公開後の修正も回数無制限です。

## 信用につながる書き方のコツ

基本項目がそろったら、次は「人柄」が伝わる工夫をします。

### 代表の顔写真を載せる

顔が見えると、それだけで安心感がちがいます。スーツでなくても、作業着や仕事中の自然な姿で大丈夫です。スマホでも、明るい場所で撮れば十分きれいに撮れます。

### 地域とのつながりを書く

「〇〇市で生まれ育ち、地元で〇年仕事をしています」のような一文は強いです。地域のお客様にとって、近くにいることは安心材料になります。

### なぜこの仕事をしているかを書く

代表あいさつには、仕事を始めたきっかけを書きましょう。

> 父の代から続く仕事を引きつぎました。「頼んでよかった」と言ってもらえる仕事を、ひとつずつ続けています。

立派な言葉は必要ありません。自分の言葉で、短く書くのがいちばん伝わります。文章のコツは[ホームページの文章の書き方](/column/homepage-bunshou-kakikata/)にまとめています。

## 紙の会社案内との違い

紙のパンフレットの会社案内を、そのまま載せればいいと思うかもしれません。でも、ホームページならではのちがいがあります。

| | 紙の会社案内 | ホームページの会社案内 |
|---|---|---|
| 読む人 | 手渡しした相手 | 検索して見つけた知らない人 |
| 情報の新しさ | 刷り直すまで古いまま | いつでも直せる |
| 地図・連絡 | 見て探す | タップで地図や電話が開く |
| 長さ | 紙の面数で決まる | 必要なだけ書ける |

ホームページの会社案内は、**まだ会ったことのない人**が読みます。だからこそ、顔写真や想いのように「人」が伝わる情報が大切です。

また、住所や電話番号が変わったら、すぐ直せるのも強みです。古い情報のままにしないよう、気づいたら直しましょう。

### 今日からできること

まずは、手元にある名刺やパンフレットを1枚用意してください。そこに書いてある社名・住所・電話番号・事業内容を、メモに書き出します。これだけで、会社概要の半分はできあがります。

あとは、スマホで代表の写真を1枚撮り、「なぜこの仕事をしているか」を3行で書いてみましょう。上手に書こうとしなくて大丈夫です。

## まとめ

- 会社案内ページは「頼んで大丈夫か」を確かめに来る人のためのページ
- 社名・代表者・所在地・連絡先・事業内容・地図などの基本項目を正確に載せる
- 代表の顔写真、地域とのつながり、仕事への想いが信用につながる
- 紙の会社案内とちがい、知らない人が読み、いつでも直せる
- 立派な言葉より、自分の言葉で短く書く
