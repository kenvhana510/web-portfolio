新年のホームページの計画は、**「変えること3つ」「やらないこと」「追う数字1つ」の3点を決めれば30分で立てられます**。「今年こそちゃんと運用しよう」と思っても、何から手をつけるか決めないまま年末を迎えてしまうのが、よくある流れです。この記事では、小さな会社・個人事業主の方が、無理なく1年続けられるホームページの年間計画の立て方をまとめます。

## 年間計画は、なぜ3つに絞るの？

ホームページでやれることは、数え上げればきりがありません。写真を撮り直す、お客様の声を集める、ブログを書く、料金表を直す、SNSとつなぐ。全部やろうとすると、結局どれも中途半端になります。

本業がある小さな会社では、ホームページにかけられる時間は、月に数時間がせいぜいです。だから**今年変えることは3つまで**にします。3つ終わったら、追加で決めればいいだけです。

よくあるのが、**1月に10個の目標を書き出したら、2月には1つもやっていなかった**ケースです。目標が多いほど、どれから始めるか迷って止まります。少ないほど動けます。

まず去年のホームページを見返して、「お客様に迷惑がかかっているところ」「問い合わせを逃しているところ」を探します。見方は[年末30分でできるチェック項目](/column/homepage-nenmatsu-tenken/)の記事がそのまま使えます。

## 「変えること3つ」はどう選べばいい？

選ぶ基準は、**お客様の問い合わせに近いものから**です。かっこよくする変更より、「問い合わせが増える」「電話での質問が減る」変更を優先します。

よくある候補を、効果が出やすい順に並べました。

| 候補 | こんな会社におすすめ |
|---|---|
| 料金の目安を載せる | 「料金はお問い合わせください」になっている |
| スマホでボタンを押しやすくする | 問い合わせの多くがスマホから来る |
| お客様の声・施工例を増やす | 似た会社が多く、比べられている |
| よくある質問を足す | 電話で同じ質問を何度も受ける |
| 対応エリア・営業時間を見直す | 去年、営業内容が変わった |
| 写真を撮り直す | 写真が5年以上前のまま |
| 採用ページを作る | 人手が足りない |

3つ選んだら、それぞれに「いつまでに」を付けます。1つめは3月まで、2つめは6月まで、3つめは9月まで、というように**年の前半に寄せる**のがコツです。後半は本業が忙しくなることが多いからです。

### よくある失敗1：デザインの変更から始めた

よくあるのが、**色やデザインを変えるのに時間をかけたら、問い合わせの数は何も変わらなかった**ケースです。見た目の変更は、お客様にとっての変化が小さいことが多いです。料金や事例など「中身」の変更を先にしましょう。

## 「やらないこと」も決めるのはなぜ？

計画で大事なのは、やることより**やらないことを先に決める**ことです。やらないと決めておけば、途中で「あれもやったほうがいいかな」と迷う時間が消えます。

小さな会社なら、次のようなものは「今年はやらない」と決めて問題ありません。

- 毎日のブログ更新（月1本で十分です）
- 全ページの作り直し
- 新しいSNSを始めること
- 広告を出すこと（問い合わせの受け皿が整ってから）
- アクセス数を増やすための細かいSEOの工夫

更新の頻度に悩んでいる方は、[ホームページの更新頻度はどれくらい？](/column/homepage-koushin-hindo/)で「最低限やる3つ」を確認してください。本当に必要な更新は、思っているより少ないです。

自分で手を動かす時間がないなら、更新を任せられる契約にしておくのも一つの手です。うちの場合は制作費0円・月額2,980円（税込）で、料金やお知らせの更新は回数無制限で月額に含まれます。「変えること3つ」をLINEで送ってもらえれば、こちらで進められます。[制作例](/#works)も参考にしてみてください。

## 追う数字は1つでいい？

はい、**1つだけ**にしてください。おすすめは「ホームページ経由の問い合わせ件数」です。

アクセス数や検索順位は、気になりますが、売上に直接つながる数字ではありません。問い合わせ件数なら、電話・LINE・フォームを数えるだけで、ツールがなくても分かります。

数え方は簡単です。

1. 問い合わせが来たら、「どこで知ったか」を一言聞く
2. 「ホームページ」「検索」と答えた件数を、月ごとにメモする
3. 月末に、先月と比べる

去年の数字が分からなければ、今年の1月から数え始めれば十分です。去年との比較より、**今年の中で増えているか**を見ます。

もう少し詳しく見たい方は、[アクセス解析で分かること・分からないこと](/column/homepage-access-kaiseki/)で、見るべき数字を3つに絞って紹介しています。

### よくある失敗2：数字を5つ追って、どれも見なくなった

よくあるのが、**アクセス数・滞在時間・順位・いいね数をぜんぶ追おうとして、3か月で見るのをやめた**ケースです。数字は増やすほど続きません。1つなら、月末に1分で終わります。

## 12か月のざっくり年間表

計画は、月ごとに「やること1つ」を書くだけで十分です。参考に、多くの業種で使える1年の流れを表にしました。自分の繁忙期に合わせて、入れ替えてください。

| 月 | やること |
|---|---|
| 1月 | 変えること3つと、追う数字を決める。年始の挨拶を載せる |
| 2月 | 変えること1つめに着手（料金の目安など） |
| 3月 | 新年度に向けた変更（営業時間・料金改定・担当者）を反映 |
| 4月 | 変えること1つめを公開。問い合わせ件数を確認 |
| 5月 | 写真を撮りためる（新緑・明るい時期は撮影向き） |
| 6月 | 変えること2つめを公開 |
| 7月 | お客様の声を集める |
| 8月 | 夏季休業のお知らせ。半年の問い合わせ件数を振り返る |
| 9月 | 変えること3つめを公開 |
| 10月 | 採用や年末商戦など、繁忙期前の情報を更新 |
| 11月 | 年末年始の営業案内を準備 |
| 12月 | 1年の見直し。来年の「変えること3つ」を決める |

この表の中で、本当に手を動かすのは「変えること3つ」の月だけです。残りの月は、お知らせを1本載せる程度で構いません。

## 計画を続けるコツはある？

コツは**月に1回、同じ日に10分だけ見直す**ことです。月初の1日、または月末の給料日など、忘れにくい日に決めます。

見直す内容は3つだけです。

- 今月の「やること」は終わったか
- 問い合わせ件数は何件だったか
- 来月の「やること」は何か

終わっていなくても、責めないでください。来月にずらすだけです。計画は守るためではなく、**迷わないためにある**と考えると気が楽になります。

## 今日からできる3ステップ

1. 去年のホームページをスマホで開き、「直したい」と思った場所を3つ書き出す
2. その3つに「3月まで」「6月まで」「9月まで」の期限を付ける
3. 今月から「ホームページ経由の問い合わせ件数」を数え始める

## まとめ

- 年間計画は「変えること3つ・やらないこと・追う数字1つ」だけ決める
- 変えることは、見た目より「料金・事例・よくある質問」など中身を優先する
- やらないことを先に決めると、途中で迷わない
- 追う数字は「ホームページ経由の問い合わせ件数」1つで十分
- 月に1回、同じ日に10分だけ見直す
