ホームページ制作の見積書は、合計金額だけで比べると失敗しやすいです。大事なのは「各項目が何のお金か」と「比べている条件がそろっているか」の2つです。ここさえ押さえれば、ITが苦手でも見積書は読めます。この記事では、よく出る項目の意味と、比べるときのチェックリストを紹介します。

## 見積書は「合計」より「中身」を見る

同じ「5ページのホームページ」でも、見積もりの金額は会社によってかなり違います。一般的には、数万円くらいから数十万円以上まで幅がある、と言われます。

金額が違うのは、ふくまれている作業がちがうからです。安く見える見積もりに、あとから必要な作業が入っていないこともあります。

だからこそ、合計の前に「何がふくまれているか」を見ましょう。

### 具体例：同じ「5ページ」でも中身がちがう

A社は、文章を書くところから写真の手配までふくむ見積もり。B社は、文章も写真もお客様が用意する前提の見積もり。この場合、B社が安く見えても、そのぶん自分の手間が増えます。

もうひとつ多いのが、毎月の費用の差です。制作費が安くても、サーバー代や保守費が別に毎月かかると、数年で見ると逆転することがあります。比べるときは「公開までの費用」と「毎月の費用」を分けて見ましょう。

## 見積書によく出てくる項目を一言で説明

見積書には、なじみのない言葉が並びます。まずは意味をざっくりつかみましょう。

| 項目 | ひとことで言うと |
|---|---|
| ディレクション | 全体の進行役・打ち合わせの費用 |
| デザイン | 見た目（色・配置）をつくる費用 |
| コーディング | デザインをWebで見られる形にする作業 |
| ページ単価 | 1ページあたりの制作費 |
| CMS構築 | 自分で更新できる仕組み（WordPressなど）を入れる費用 |
| サーバー・ドメイン | ホームページを置く場所と、住所（〇〇.jp）の費用 |
| 保守・管理 | 公開後の更新や不具合対応の費用 |

会社によって、名前が少しちがうこともあります。分からない項目があれば、遠慮なく「これは何の作業ですか？」と聞いてかまいません。

### 「一式」と書かれている項目に注意

「制作費 一式」のように、まとめて書かれている場合もあります。中身が分からないときは、何ページで、どこまでの作業がふくまれるかを確認しましょう。

## 比べるときのチェックリスト

複数の見積もりを比べるときは、次の項目を順番に確かめます。

- **ページ数と中身は同じ条件か**（同じ5ページでも、文章を書くのは誰か）
- **スマホ対応はふくまれているか**
- **写真や文章の用意は、自分か制作会社か**
- **サーバー・ドメイン代は入っているか、別か**
- **公開後の修正は有料か、無料か、回数は何回までか**
- **自分で更新できる範囲はどこまでか**
- **毎月の費用（保守・管理費）はいくらか**
- **ホームページやドメインの所有権は誰にあるか**
- **解約したとき、サイトはどうなるか**

特に見落としやすいのが、**公開後の費用**と**所有権**です。制作費が安くても、修正のたびに費用がかかる場合があります。また、解約するとサイトが使えなくなる契約もあります。

### よくある勘違い：項目が多いほど高くて損

項目がこまかく分かれている見積もりは、高く見えがちです。でも実は、何にお金がかかるかが分かる、親切な見積もりとも言えます。逆に「一式」だけの見積もりは、あとで「それはふくまれていません」となりやすいので注意しましょう。

月額費用の考え方は、[ホームページの月額費用の相場](/column/homepage-getsugaku-hiyou-souba/)でもくわしく書いています。

## LEGACRAFTは見積りが要らないプラン1つだけ

うちの場合は、料金プランが1つだけなので、見積書をつくる必要がありません。

- 制作費0円、月額2,980円（税込）、24ヶ月契約（総額71,520円）
- 5ページ程度の制作、スマホ対応、WordPress構築がふくまれる
- サーバー費用・常時SSL、お問い合わせフォームもふくまれる
- 公開後の更新・修正は回数無制限、LINEで相談できる
- 実費は独自ドメインの取得・更新費（年額）のみ

24ヶ月たったあとは、WordPressのデータとドメインを完全にお渡しします。途中解約は原則できませんが、そのぶん制作費を0円にしています。

ただし、ネットショップや予約システム、多言語対応など大きな機能は、別途お見積りになります。

## 見積もりをとる前に用意しておくと楽なもの

見積もりは、こちらの希望がはっきりしているほど正確になります。次のことを、メモでいいのでまとめておきましょう。

1. ホームページで何をしたいか（問い合わせを増やす、採用、信用づくり など）
2. 載せたいページ（サービス、会社案内、よくある質問 など）
3. 写真や文章は自分で用意できるか
4. 参考にしたいホームページがあるか
5. いつまでに公開したいか

同じメモを各社に渡せば、条件がそろって比べやすくなります。制作会社の選び方は、[制作会社の選び方](/column/seisaku-gaisha-erabikata/)も参考にしてください。

## まとめ

- 見積書は合計金額より「何がふくまれているか」を見る
- ディレクション・コーディング・CMSなど、項目の意味をざっくり知っておく
- 比べるときは、ページ数と中身、公開後の修正費、更新できる範囲、所有権をそろえる
- 同じ希望メモを各社に渡すと比べやすい
- LEGACRAFTはプラン1つで見積り不要（大きな機能だけ別途見積り）

料金のくわしい内容は[料金ページ](/#price)で確認できます。気になる点はLINEで気軽に聞いてください。
