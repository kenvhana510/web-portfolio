農家・農園のホームページは、**「直売で買いたい個人」「仕入れたい飲食店や小売」「体験に来たい家族」の3つの導線を分ける**と、問い合わせが増えます。どんなに良い野菜や米を作っていても、「どうやって買えるのか」が分からなければ、ホームページは見て終わりです。この記事では、農家が載せる内容と構成、収穫時期カレンダー、こだわりの書き方、注文と発送の条件の書き方をまとめます。

## 農家のホームページは、誰が見に来る？

農家のホームページに来るのは、主に3種類の人です。それぞれ、知りたいことが違います。

| 見に来る人 | 知りたいこと | 決め手 |
|---|---|---|
| 直売で買いたい個人 | 何が、いつ、いくらで買えるか。送料はいくらか | 味の想像がつく写真と、注文の簡単さ |
| 飲食店・小売・加工業者 | 安定して仕入れられるか。量・規格・時期・価格帯 | 栽培の情報と、連絡の取りやすさ |
| 体験・観光で来たい家族 | いつ何が採れるか、料金、予約、駐車場、雨の日 | 子ども連れで困らない情報 |

多いのが、この3つを1つのページに混ぜてしまうことです。個人のお客様に向けて「規格」や「ロット」の話をしても伝わりませんし、飲食店に「ご家族で楽しめます」と書いても響きません。入口を分けるだけで、それぞれに届くホームページになります。

## ページ構成はどう作ればいい？

基本は次の7ページです。小さな農園なら、6と7はまとめても大丈夫です。

1. トップ：畑と作物の写真、地域、何を作っているか、3つの入口ボタン
2. 作物とこだわり：品目ごとの説明と、栽培の考え方
3. 収穫カレンダー：月ごとに何が採れるか
4. ご購入方法（個人向け）：直売所・通販・定期便、送料、支払い
5. 業務用のお取引（法人向け）：対応できる量・時期・規格、連絡方法
6. 収穫体験・見学：料金、予約、持ち物、雨天時
7. 農園について：場所、家族やスタッフ、歴史

トップの最初の一文は、「○○県○○市で、米と季節の野菜を育てている○○農園です。直売・通販・飲食店さまへの卸をしています」のように、地域と作物とできることを入れます。地域名の入れ方は[地域名＋業種で検索されるには](/column/chiiki-gyoushu-kensaku/)を参考にしてください。

### よくある失敗1：「こだわり」だけで、買い方がない

よくあるのが、**土づくりや農法の話を長く書いたのに、どこで買えるかがどこにも書かれていない**ケースです。こだわりは大事ですが、それは「買う理由」であって「買い方」ではありません。両方そろって、初めて注文につながります。

## 収穫時期のカレンダーは、どう載せればいい？

農家のホームページで一番役に立つのが、**収穫カレンダー**です。「今、何が買えるのか」が一目で分かり、お客様の「売り切れでがっかり」も減ります。

そのまま使える形です。○には自分の作物を入れてください。

| 作物 | 1〜2月 | 3〜4月 | 5〜6月 | 7〜8月 | 9〜10月 | 11〜12月 |
|---|---|---|---|---|---|---|
| 米（新米） | | | | | ● | ● |
| トマト | | | ● | ● | | |
| ○○ | | ● | ● | | | |
| ○○ | ● | | | | | ● |

カレンダーの下には、次の一文を添えます。

> 天候により、時期が前後することがあります。最新の状況はお知らせでご案内します。

これがあると、「書いてあったのに買えなかった」というクレームを防げます。お知らせの出し方は[ホームページの更新頻度](/column/homepage-koushin-hindo/)の記事を参考にしてください。

## 注文方法と発送の条件は、どう書けばいい？

個人のお客様向けには、**「何を・いくらで・どう頼んで・いつ届くか」**を一か所にまとめます。文例です。

> 季節の野菜セット（5〜7品）：○,○○○円（送料別）
> ご注文はLINE・お電話・注文フォームで受け付けています。
> 発送は毎週○曜日。ご注文の締切は前日の正午までです。
> 送料は地域により○○円〜○,○○○円。クール便が必要な時期は別途○○円をいただきます。
> お支払いは、銀行振込・代金引換・クレジットカードからお選びいただけます。

書いておくと問い合わせが減る項目は次のとおりです。

- □ 品目と価格（または価格の目安）
- □ 注文方法と締切
- □ 発送日と到着の目安
- □ 送料とクール便の条件
- □ 支払い方法
- □ 直売所の場所と営業日
- □ 定期便の内容と、止め方・休み方

### よくある失敗2：注文がメールだけで、返事が遅れた

農作業中はメールを見られません。**LINEで受けて、作業の合間にスマホで返す**ほうが続きます。つなぎ方は[LINE公式アカウントとホームページの連携](/column/line-koushiki-homepage-renkei/)にまとめています。

うちの場合は制作費0円・月額2,980円（税込）で、収穫カレンダーや価格の差し替え、季節のお知らせの投稿も月額に含まれます。農作業で忙しい方ほど、更新を任せられる仕組みが向いています。[制作例](/#works)も見てみてください。

## 飲食店や小売に卸したいなら、何を書く？

法人向けのページは、**「安定して、どのくらいの量を、どの時期に出せるか」**が中心です。個人向けとは、知りたいことがまったく違います。

載せる項目は次のとおりです。

- 対応できる品目と、出荷できる時期
- 1回あたりの量の目安と、最低の注文量
- 規格（サイズ・箱の単位）と、規格外品の扱い
- 納品方法（配達・発送・引き取り）と対応エリア
- 価格の決め方（市況連動か固定か、見積もり対応か）
- 取引の実績（店名が出せない場合は「市内の飲食店○軒」で十分）
- 連絡方法と、返事ができる時間帯

飲食店の担当者が上司に説明しやすい情報を載せる、という考え方は[BtoBサイト制作のコツ](/column/btob-site-tsukurikata/)と同じです。

### よくある失敗3：価格を一切書かなかった

「価格はお問い合わせください」だけだと、忙しい仕入れ担当者は問い合わせません。目安でもいいので、「○kg箱で○,○○○円前後」「時期により変動」のように書いておくと、最初の連絡が来やすくなります。

## 写真と動画は、どう使えばいい？

農家のホームページで一番強いのは、**畑と作業と作物の写真**です。フリー素材ではなく、自分の畑を撮ります。

- 朝の畑、収穫の手元、箱に詰めた作物の3種類を押さえる
- 季節ごとに撮りためて、カレンダーのそばに置く
- 家族やスタッフの顔が出ると、信用が一段上がる

短い動画も効きます。収穫の様子を30秒撮ってトップに置くだけで、作物の雰囲気が伝わります。載せ方は[ホームページに動画を埋め込む方法](/column/homepage-douga-umekomi/)を参考にしてください。Instagramは「今日の畑」、ホームページは「買い方と条件」と分けると、両方が活きます。

## 今日からできる3ステップ

1. 自分の作物で収穫カレンダーの表を埋める
2. 個人向けの注文方法（締切・発送日・送料・支払い）を文例にそって書く
3. 畑・収穫・箱詰めの写真を各1枚、スマホで撮る

## まとめ

- 見に来る人は「個人」「法人」「体験」の3種類。入口を分ける
- こだわりは「買う理由」。買い方とセットで初めて注文になる
- 収穫カレンダーは一番役に立つページ。時期が前後する注意書きを添える
- 個人向けは締切・発送日・送料・支払いを一か所に。法人向けは量・時期・規格を書く
- 写真は自分の畑を撮る。更新はLINEで受けて、作業の合間に返す
