ホームページの予算は、**初期費用ではなく「年間でいくら」「月でいくら」で考える**と判断を間違えません。見積もりの一番大きな数字だけを見て決めると、公開後の更新費や毎年の維持費で「思ったより高い」となるからです。この記事では、初期費用型と月額型の年間総額の比べ方、見落としがちな費用、そして「いくらまでなら出していいか」を自分の商売の数字から決める方法をまとめます。

## 初期費用だけで判断すると、なぜ失敗する？

ホームページの費用は、公開した日で終わりません。むしろ、公開後のほうが長く続きます。

- 毎年かかるもの：ドメイン、サーバー、SSL（鍵マーク）
- 不定期にかかるもの：文章や写真の修正、ページの追加、不具合の対応
- 数年に一度かかるもの：リニューアル、仕組みの引っ越し

よくあるのが、**初期費用の安さで選んだら、営業時間を1行直すだけで毎回費用がかかり、結局直さなくなった**ケースです。直さないホームページは、情報が古くなって信用を落とします。費用の内訳は[ホームページの月額費用の相場](/column/homepage-getsugaku-hiyou-souba/)で、初期費用の幅は[ホームページ制作の費用相場](/column/homepage-seisaku-hiyou-souba/)で説明しています。ここでは、その2つを「年間」でまとめて見る考え方を扱います。

## 年間総額はどう比べる？

比べるときは、同じ年数で「全部足した金額」をそろえます。例として、2年間（24か月）で比べた表です。金額は考え方を示すための例で、実際の見積もりに置き換えてください。

| 費用の種類 | 初期費用型（例） | 月額型（例） |
|---|---|---|
| 制作費 | ○○万円（最初に一括） | 0円 |
| 月々の費用 | 保守料 月○千円 | 月額○千円 |
| ドメイン・サーバー | 年○千円（別途） | 月額に含むか確認 |
| 文章・写真の修正 | 1回○千円〜 | 月額に含むか確認 |
| ページ追加 | 1ページ○万円〜 | 月額に含むか確認 |
| **2年間の合計** | 制作費＋保守24か月＋修正の回数分 | 月額×24か月 |

表を埋めるときのコツは、「修正は年に何回するか」を正直に見積もることです。営業時間、料金、スタッフ、お知らせ。小さな会社でも、年に5〜10回は直すことが出てきます。その回数をかけ算して、初めて初期費用型の本当の年額が分かります。

月額型は、月額に「何が含まれるか」で年間の金額が変わります。[サブスク型ホームページのメリット・デメリット](/column/subscription-homepage-merit-demerit/)で書いた確認5点を、見積もりの段階で聞いておいてください。

### よくある失敗：見落としがちな費用

- **ドメインの更新料**：年に1回。忘れると、ホームページが消える
- **サーバー代**：月額か年額か。制作費に「初年度分だけ」含まれていることがある
- **SSL**：無料のものと有料のものがある。更新作業が必要な場合も
- **写真**：カメラマンに頼むと別料金。自分で撮るなら時間がかかる
- **自分の作業時間**：文章を書く、写真を選ぶ、確認する時間も「費用」

うちの場合は、制作費0円・月額2,980円（税込）で、サーバーも更新作業（回数無制限）も月額に含まれます。年間にすると月額×12か月で、追加の費用を計算しなくていいのが特徴です。24ヶ月後にはサイトを譲渡するので、その先の持ち方も選べます。[制作例](/#works)で、月額の範囲でどこまで作れるかを見てみてください。

## 予算は「1件の受注の利益」から決める

「いくらまで出していいか」は、相場ではなく、自分の商売の数字で決めます。考え方は簡単です。

1. お客様1件あたりの**利益**（売上ではなく、残るお金）を出す
2. ホームページから、年に何件の問い合わせが来れば元が取れるかを計算する
3. その件数が「現実的」なら、その予算は出していい

たとえば、1件の利益が3万円の商売なら、年間の費用が12万円でも、年に4件の受注で元が取れます。月に1件に満たない数です。逆に、1件の利益が3千円の商売で年間30万円のホームページを持つと、100件の受注が必要になります。この場合は、予算を下げるか、ホームページ以外の集客を先に考えたほうがいいでしょう。

問い合わせの件数は、[アクセス解析で分かること](/column/homepage-access-kaiseki/)の「見るべき数字3つ」で追えます。年間予算を決めたら、その数字が目標になります。

### 費用は「経費」として考える

ホームページの費用は、商売の経費です。帳簿での扱いは、内容によって「その年の経費」になる場合と「資産として数年に分けて計上」する場合があるとされています。月額型は毎月の費用として扱いやすい、という声もあります。扱いは会社の状況によって変わるので、**税理士か税務署に確認**してください。考え方の整理は[ホームページの減価償却と耐用年数の考え方](/column/homepage-genka-shoukyaku/)と[ホームページ作成費用の勘定科目](/column/homepage-hiyou-kanjou-kamoku/)で説明しています。

## 年間予算を1枚にまとめる

最後に、決めた予算を1枚の表にしておきます。年の途中で「あれ、いくらだったっけ」がなくなります。

| 項目 | 金額 | 支払い時期 |
|---|---|---|
| 月額（制作・保守・サーバー） | 月○,○○○円 | 毎月 |
| ドメイン | 年○,○○○円 | ○月 |
| 写真撮影 | ○○,○○○円 | 必要なとき |
| 年間合計 | ○○○,○○○円 | |
| 元を取るのに必要な受注 | 年○件 | |

よくあるのが、**ドメインの更新を「月額に含まれている」と思い込んでいて、更新の案内メールを無視してホームページが止まった**ケースです。支払い時期の欄を書くと、こうした事故を防げます。

## 今日からできる3ステップ

1. 今のホームページにかかっている費用を、年間の合計で書き出す（ドメイン・サーバー・修正代を忘れずに）
2. お客様1件あたりの利益を出し、年に何件で元が取れるかを計算する
3. 上の表に予算と支払い時期を書き、カレンダーにドメインの更新月を入れる

## まとめ

- ホームページの予算は、初期費用ではなく「年間」「月額」で考える
- 初期費用型は、修正の回数をかけ算して本当の年額を出す
- ドメイン・サーバー・SSL・写真・自分の時間が、見落としやすい費用
- 出していい予算は「1件の利益×現実的な受注件数」から決める
- 予算を1枚の表にし、支払い時期を書いておく。税務の扱いは専門家に確認する
