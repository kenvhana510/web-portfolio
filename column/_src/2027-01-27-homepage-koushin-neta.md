ホームページの更新ネタは、**「月ごとの出来事」と「いつでも使える定番ネタ」を一覧にしておけば尽きません**。「何を書けばいいか分からない」で止まっている人は、ネタがないのではなく、ネタを探すタイミングを決めていないだけです。この記事では、1〜12月の月別ネタ表、業種を問わず使える定番ネタ10個、1本200字で済む書き方をまとめます。

## 更新ネタが尽きるのはなぜ？

更新が止まる理由は、だいたい次の2つです。

- 「ちゃんとした記事」を書こうとして、ハードルが上がっている
- 書くタイミングを決めていないので、思い出したときには忘れている

まず、ちゃんとした記事はいりません。[ホームページの更新頻度](/column/homepage-koushin-hindo/)で書いたとおり、お客様が見たいのは「今も営業していて、情報が新しいこと」です。200字のお知らせで十分です。

次に、ネタは「探す」のではなく「拾う」ものです。日々の仕事の中で起きたことを、そのまま書く。そのために、月ごとに「この時期はこれが起きる」をあらかじめ表にしておきます。

よくあるのが、**年始に「今年は毎週更新する」と決めて、2月で止まった**ケースです。頻度を決めるより、ネタの置き場所を決めるほうが長続きします。

## 月別の更新ネタ一覧表

カレンダーに沿って、どの業種でも起きやすい出来事を並べました。自分の業種に合うものを選んで、手帳に書き写してください。

| 月 | 更新ネタの例 |
|---|---|
| 1月 | 新年の挨拶、今年の目標、年始の営業開始日、冬の休業日 |
| 2月 | 年度末に向けた繁忙期のお知らせ、確定申告に関わる書類の案内（士業など）、バレンタイン企画 |
| 3月 | 年度末の営業日、料金改定や新サービスの予告、卒業・引っ越しシーズンの対応 |
| 4月 | 新年度の挨拶、新スタッフの紹介、料金・営業時間の変更、春の施工・商品 |
| 5月 | ゴールデンウィークの営業日、新生活のお悩み相談、初夏の準備 |
| 6月 | 梅雨の対策（住まい・衣類・体調）、上半期の振り返り、夏季の予約開始 |
| 7月 | 夏休みの営業日、暑さ対策、お盆の予約締切 |
| 8月 | お盆休みのお知らせ、休み明けの営業日、夏の実績紹介 |
| 9月 | 秋の繁忙期予告、台風時の対応、年末に向けた予約開始 |
| 10月 | 年末年始の予約受付、秋の施工事例、新商品 |

| 12月 | 年末年始の休業日、1年のお礼、年内の最終受付日 |

季節のお知らせの文例は、[年末年始休業のお知らせ例文](/column/nenmatsu-nenshi-kyugyou-oshirase/)と[新年の挨拶をホームページに載せる例文](/column/nenshi-aisatsu-homepage/)にまとめています。

## 業種を問わない定番ネタ10個

月の出来事がない週は、次の10個から選びます。どれも仕事の中で自然に起きることです。

1. **お客様からよく聞かれた質問と答え**（1つで1本になる）
2. **最近の仕事の紹介**（写真1枚と、どんな依頼だったか）
3. **お客様の声**（許可をもらった一言を載せる）
4. **新しく始めたこと**（サービス、道具、支払い方法）
5. **スタッフの近況**（資格を取った、入社した、研修に行った）
6. **料金や営業時間の変更**（変更がなくても「変わっていません」と書ける）
7. **道具や材料のこだわり**（なぜそれを選んでいるか）
8. **地域の話題**（近くのイベント、道路工事で駐車場が使いにくい、など）
9. **季節ごとの注意点**（この時期に多い相談、早めにやるといいこと）
10. **失敗談と学んだこと**（信用につながる。無理に書かなくていい）

よくあるのが、**「お客様の質問」は毎日答えているのに、ホームページに書いていない**ケースです。電話で3回同じことを聞かれたら、それは更新ネタです。答えをそのまま載せれば、[よくある質問ページ](/column/yokuaru-shitsumon-page/)にもなります。

ネタがあっても「更新のやり方が分からない」で止まることもあります。うちの場合は制作費0円・月額2,980円（税込）で、お知らせの追加や文章の差し替えは回数無制限で月額に含まれます。LINEで「これ載せて」と写真と文を送るだけなので、ネタさえあれば更新は止まりません。[制作例](/#works)の業種別デモも参考にしてください。

## 1本200字で十分な書き方

更新は、次の3行で完成です。

1. 何があったか（1文）
2. お客様にどう関係するか（1〜2文）
3. 問い合わせや予約への一言（1文）

例文です。

> 4月から、キャッシュレス決済が使えるようになりました。
> これまで現金のみでしたが、クレジットカードと主なスマホ決済に対応しました。お支払いのときにお申し付けください。
> ご不明な点は、お気軽にお問い合わせください。

これで約100字です。写真を1枚つければ、立派なお知らせになります。長く書く必要はありません。むしろ短いほうが、スマホで読まれます。

### お知らせとブログ、どっちに書く？

ざっくり分けると、次のとおりです。

- **お知らせ**：営業日、料金、変更など「今知ってほしいこと」。古くなったら消していい
- **ブログ（コラム）**：質問への答え、こだわり、事例など「あとから読んでも役に立つこと」。残しておく

迷ったらお知らせでかまいません。詳しい使い分けは[ホームページとブログの違い](/column/homepage-to-blog-chigai/)で説明しています。自分で更新する範囲を決めたい人は、[ホームページを自分で更新する方法](/column/homepage-jibun-de-koushin/)も参考にしてください。

## ネタを拾う仕組みを作る

最後に、ネタが自然に集まる仕組みを3つ紹介します。

- **スマホのメモに「HPネタ」を作る**：お客様に聞かれたこと、現場で撮った写真を、その場で放り込む
- **月初に5分だけカレンダーを見る**：上の表から、今月のネタを1つ選ぶ
- **更新する曜日を決める**：毎週でなくていい。「第1月曜」のように月1回でも、決めておくと続く

よくあるのが、**写真はたくさん撮っているのに、どれを載せるか迷って全部お蔵入り**になるケースです。迷ったら、一番新しい1枚でかまいません。

## 今日からできる3ステップ

1. 上の月別表から、今月と来月のネタを1つずつ手帳に書く
2. スマホのメモに「HPネタ」を作り、お客様に聞かれたことを1つ入れる
3. 定番ネタ10個のうち1つを、3行200字で書いて公開する

## まとめ

- 更新ネタは「月ごとの出来事」と「定番ネタ10個」の一覧から拾う
- 1本は3行200字で十分。長い記事は書かなくていい
- お客様に3回聞かれたことは、そのまま更新ネタになる
- お知らせは「今知ってほしいこと」、ブログは「あとから役に立つこと」
- ネタの置き場所と更新する日を決めると、止まらない
