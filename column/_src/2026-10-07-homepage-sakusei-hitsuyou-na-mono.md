ホームページ作成に必要なものは、大きく分けて「仕組み」と「中身」の2種類です。
仕組み（ドメイン・サーバー・SSL）は、業者にまかせればOK。
あなたが用意するのは中身だけ。しかも、写真と文章はあとからでも大丈夫です。
「何から手をつければいいか分からない」という方のために、必要なものを一覧にしました。

## 結論：あなたが用意するのは「会社の基本情報」だけ

まず安心してほしいのは、難しい準備はいらないということです。
ホームページに必要なものの大半は、制作する側が用意します。

あなたが最初に用意するのは、次の3つだけ。

- 会社名（屋号）、住所、電話番号
- 何をしている会社か（ひとことでOK）
- 問い合わせを受けたい連絡先（電話、メール、LINEなど）

これだけあれば、相談は始められます。
写真と文章は、作りながら集めていけば間に合います。

## ホームページに必要なもの一覧

まずは全体像を見てみましょう。
ざっくり「仕組み」「中身」「あると良いもの」の3つに分かれます。

| 分類 | 必要なもの | ひとことで言うと |
| --- | --- | --- |
| 仕組み | ドメイン | ホームページの住所（例：〇〇.jp） |
| 仕組み | サーバー | ホームページを置いておく場所 |
| 仕組み | SSL | 通信を暗号化する鍵マーク（今は必須） |
| 中身 | 会社情報 | 会社名、住所、営業時間など |
| 中身 | サービス内容 | 何を、誰に、いくらで提供しているか |
| 中身 | 問い合わせ先 | 電話番号、フォーム、LINEなど |
| 中身 | 写真 | 外観、スタッフ、作業風景など |
| 中身 | 文章 | あいさつ、サービス説明など |
| あると良い | ロゴ | なければ文字だけで作れる |
| あると良い | 地図 | Googleマップを貼れば完成 |

こうして見ると、多く感じるかもしれません。
でも「仕組み」の3つは、あなたが触る必要はありません。

## 「依頼する場合に用意するもの」と「業者がやること」

業者に頼む場合、役割分担はこうなります。
表にすると、あなたの仕事が意外と少ないことが分かります。

| あなたが用意するもの | 業者がやること |
| --- | --- |
| 会社名・住所・電話番号 | ドメインの取得代行・設定 |
| サービスの内容と料金 | サーバーの契約・設定 |
| 問い合わせを受けたい方法 | SSL（鍵マーク）の設定 |
| 写真（スマホでOK） | デザインとページの組み立て |
| 伝えたいことのメモ | 文章の整理・清書 |
| ロゴ（あれば） | お問い合わせフォームの設置 |
| ― | Googleマップ・SNSリンクの設置 |
| ― | スマホ対応、検索されるための基本設定 |

ポイントは、文章を「完成させて渡す」必要はないことです。
箇条書きのメモや、口頭で話した内容を、業者が整えるのが普通です。

> **ここまでのまとめ**
> ・ドメイン、サーバー、SSLは業者まかせでOK
> ・あなたが用意するのは会社情報と連絡先
> ・写真はスマホ、文章はメモで十分

うちの場合は、ドメインの取得代行からサーバー、SSL、フォーム、地図まで月額に含めています。
実費としてかかるのは、独自ドメインの年額だけです。
「何を用意すればいいか」から一緒に整理するので、手ぶらで相談に来てもらって大丈夫です。

## 写真と文章がなくても始められる理由

「写真も文章もないから、まだ相談できない」。
これが、いちばん多いお悩みです。でも順番が逆です。

ホームページ作りは、相談してから素材を集めるのが普通の流れです。
理由は3つあります。

1. **何の写真が必要かは、ページ構成が決まってから分かる**
   先に撮っても、使わない写真が増えるだけです。
2. **文章はヒアリングで引き出すもの**
   質問に答えるだけで、業者側が形にします。
3. **仕組みの準備は素材と並行して進められる**
   ドメインやサーバーの手配に、写真は関係ありません。

つまり、先に相談したほうが、ムダなく準備できます。
写真の撮り方は[ホームページの写真はスマホで十分](/column/homepage-shashin-sumaho/)、文章の書き方は[ホームページの文章の書き方](/column/homepage-bunshou-kakikata/)で詳しく説明しています。

## ロゴがなくても大丈夫

「ロゴを作ってからじゃないと…」と止まってしまう方も多いです。
でも、ロゴは必須ではありません。

会社名を読みやすい文字で置くだけで、十分きれいに見えます。
実際、文字だけのロゴ（ロゴタイプ）で運営している会社はたくさんあります。

ロゴはあとから作って差し替えられます。
最初から全部そろえようとしないことが、早く公開するコツです。

## 用意するときの小さな注意点

準備を始める前に、知っておくと迷わないポイントです。

- **ドメインは自分の名義にしてもらう**
  あとで引っ越すときに困らないように、確認しておきましょう。
- **写真は他のサイトから借りない**
  無断で使うと、著作権の問題になります。自分で撮るか、使ってよい素材を使います。
- **連絡先は「本当に対応できるもの」にする**
  電話に出られないなら、フォームやLINEを主にするのも手です。
- **料金を載せるか決めておく**
  「要相談」でも構いませんが、目安があるほうが問い合わせは来やすいです。

5ページの中身を具体的に知りたい方は、[小さな会社のホームページは5ページで十分](/column/homepage-5page-kousei/)も参考にしてください。

## まとめ

- ホームページに必要なものは「仕組み」と「中身」の2種類
- ドメイン・サーバー・SSLは業者がやるので、あなたは触らなくていい
- あなたが用意するのは会社情報と連絡先、それだけで相談は始められる
- 写真はスマホ、文章はメモで十分。業者が整える
- ロゴはなくてもOK。あとから足せばいい

うちの場合は、制作費0円・月額2,980円（税込）の1プランで、仕組みの部分はすべて含まれています。
素材がそろってから14日間で公開できます。
「まだ何もないけど、そろそろ作りたい」という段階で、LINEで相談してもらえれば一緒に整理します。
