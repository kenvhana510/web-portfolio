ホームページのサーバーとは？｜無料と有料の違いと費用の考え方

ホームページのサーバーとは、ホームページを置いておく「土地」のことです。サーバーが無いと、ホームページはインターネットに出せません。無料のサーバーもありますが、仕事で使うなら注意点があります。この記事では、サーバーの意味と、無料・有料の違い、費用の考え方をまとめます。

サーバーは「土地」、ドメインは「住所」

ホームページの仕組みは、家にたとえるとわかりやすいです。

たとえホームページでいうとひとことで
土地サーバーホームページのデータを置く場所
住所ドメイン「〇〇.jp」のようなアドレス
家ホームページお客様が見るページそのもの

お客様は、住所（ドメイン）をたよりに、土地（サーバー）に建っている家（ホームページ）を訪ねてきます。どれか1つ欠けても、ホームページは見られません。

住所の決め方は独自ドメインの選び方で解説しています。

サーバーがやっていること

サーバーは、ホームページの文章や写真をずっと保管しています。お客様がアドレスを開くと、そのデータを届けて、画面に表示させます。

つまり、24時間ずっと動き続けているお店の倉庫のようなものです。サーバーが止まると、ホームページも見られなくなります。

お問い合わせフォームや、WordPress（自分で更新できるホームページの仕組み）を動かすのも、サーバーの役目です。

無料サーバーの注意点

無料で使えるサーバーもあります。お金をかけずに始められるのは魅力です。ただ、仕事で使うなら、次のような点に注意が必要です。

広告が出ることがある

無料サーバーの中には、ホームページに広告が表示されるものがあります。自分の会社と関係ない広告が出ると、お客様は戸惑います。

容量や機能に制限がある

置けるデータの量が少なかったり、使える機能が限られたりします。写真をたくさん載せたい、WordPressを使いたい、という場合に困ることがあります。

サービスが終わるリスクがある

無料のサービスは、運営する会社の都合で終わることがあります。そうなると、ホームページを別の場所へ引っ越す必要があります。

ポイント：無料サーバーは「お試し」には便利。会社の看板として長く使うなら、有料サーバーが安心です。

無料ツール全般の注意点は無料ホームページツールの落とし穴にもまとめています。

有料サーバーの費用の考え方

有料サーバーの費用は、プランや会社によってさまざまです。一般的には、月数百円〜数千円くらいが多いと言われます。

小さな会社やお店のホームページなら、高いプランでなくても足りることが多いです。大事なのは、値段だけで決めないことです。

選ぶときに確認したいこと

  1. WordPressが使えるか
  2. SSL（通信を守る仕組み）が無料で使えるか
  3. データのバックアップ（予備の保存）があるか
  4. 困ったときに相談できる窓口があるか
  5. 契約期間と、更新のときの料金

SSLについてはホームページのSSLとはでくわしく解説しています。

具体例：こんな場合はどう選ぶ？

会社案内が中心の5ページくらいのホームページの場合は、入門向けのプランで足りることが多いです。大事なのは、WordPressとSSLが使えることです。

写真をたくさん載せたい場合は、容量に余裕のあるプランを選びましょう。施工事例やメニューの写真を増やしていくと、少しずつデータがふえていきます。

ネットショップや予約の仕組みを入れたい場合は、それに対応しているかを先に確認します。あとから「この機能は使えない」とわかると、引っ越しが必要になります。

よくある勘違い：サーバーが速ければ集客できる

サーバーの性能が良いと、ページの表示は安定します。でも、それだけでお客様が増えるわけではありません。人が来るかどうかは、ページの中身や、見つけてもらう工夫で決まります。

小さな会社なら、サーバーは「ふつうに安定して動けば十分」と考えてOKです。集客の考え方はホームページの集客方法にまとめています。

自分で契約・管理するのは手間がかかる

サーバーは、借りたら終わりではありません。更新の手続き、支払い、トラブルへの対応など、管理が続きます。

ITが苦手な方にとっては、ここが意外な負担です。更新を忘れて、ある日ホームページが見られなくなった、という話もあります。

今日からできること

いまホームページがある方は、次の3つを確認してみてください。

  1. サーバーの契約者がだれか（自分か、制作会社か）
  2. 支払いがどのカードや口座から引き落とされているか
  3. 更新のお知らせメールが、だれのアドレスに届くか

どれか1つでもわからないなら、早めに整理しておくと安心です。

うちの場合、サーバー費用は月額2,980円（税込）にふくまれています。お客様が自分でサーバーを契約したり、管理したりする必要はありません。常時SSLも月額の中に入っています。

まとめ

  • サーバーは、ホームページを置いておく「土地」
  • ドメインは「住所」。土地と住所がそろって、はじめてホームページが見られる
  • 無料サーバーは、広告・容量や機能の制限・サービス終了に注意
  • 有料サーバーは、月数百円〜数千円くらいが多いと言われる
  • 契約や管理の手間もふくめて、どう持つかを考える

独自ドメインとは？｜ホームページの住所の選び方と費用の目安

独自ドメインとは、ホームページの「自分だけの住所」です。持っておくと引っ越しても住所が変わらず、信用にもつながります。選び方のコツ、費用の目安、名義でもめないための注意点をやさしく解説します。
