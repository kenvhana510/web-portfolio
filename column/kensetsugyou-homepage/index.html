建設業にホームページは必要？｜工務店・職人が載せるべき内容と採用への効果

結論から言います。建設業・工務店・職人にも、ホームページは必要です。理由は、あなたの会社を調べる人が、元請け・施主・求職者の3種類いて、全員がまず検索するからです。

「うちは紹介だけで回ってるから」という会社ほど、実は危ないです。紹介してくれる人も、紹介された人も、会う前にスマホで社名を検索します。そのとき何も出てこないと、話が止まります。

この記事では、建設業のホームページに誰が何を求めているのか、何を載せればいいのか、採用にどう効くのかをお話しします。

「紹介だけで回っている」会社こそ、次の世代のために

まず、今のあなたの会社が困っていないことは分かります。長年の付き合いがあって、電話1本で仕事が来る。それは本当に強いことです。

でも、少し先を考えてみてください。今の元請けの担当者が代替わりしたとき。付き合いのある施主さんの子ども世代が家を建てるとき。そして、あなたの会社に若い人を入れたいとき。

その人たちは全員、スマホで探します。「社名で検索して何も出てこない会社」は、その時点で候補から外れやすい。今のお客さんのためではなく、次の世代のお客さんと社員のために、ホームページは要ります。

建設業のホームページを見る3種類の人

建設業のホームページは、見る人が3種類います。それぞれ、知りたいことがぜんぜん違います。

見る人知りたいこと載せるべきもの
元請け・取引先実在する会社か、信用できるか会社概要、許可番号、保険、施工実績
施主（一般のお客さん）どんな工事ができるか、人柄施工事例の写真、職人の顔、流れと費用感
求職者どんな職場か、待遇、雰囲気現場の写真、先輩の声、休みと給与の目安

元請け・取引先が見るもの

元請けの担当者は、新しい協力会社を探すとき、まず「ちゃんとした会社か」を確認します。建設業許可の番号、加入している保険、所在地、代表者名。これが載っているだけで安心されます。

逆に、載っていないと「個人でやってる人かな？」「何かあったとき大丈夫かな？」と不安を持たれます。会社の実在を証明するのが、ホームページの第一の仕事です。

施主が見るもの

一般のお客さんは、まず「どんなものができるのか」を見たい。だから施工事例の写真がいちばん大事です。次に見るのが「誰がやるのか」。職人さんの顔写真と、ひとこと紹介があるだけで、問い合わせのハードルがぐっと下がります。

求職者が見るもの

若い人や転職を考える人は、「この会社で働いたらどうなるか」を想像したい。現場の雰囲気、先輩がどんな人か、休みは取れるのか。きれいな言葉より、普段の現場写真のほうが伝わります。

載せるべき内容と、5ページの構成例

建設業のホームページは、最初から大きなものは要りません。5ページくらいで十分です。

  1. トップ：何の工事をしている会社か、対応エリア、代表的な施工写真を1〜3枚
  2. 施工事例：工事の種類ごとに、写真と簡単な説明（工期、市町村名、工事内容）
  3. 会社案内：会社概要、建設業許可番号、保険加入状況、代表あいさつ、職人の紹介
  4. 採用情報：募集職種、仕事の流れ、1日のスケジュール、先輩のひとこと
  5. お問い合わせ：フォーム、電話番号、LINEなど、連絡しやすい方法を複数

施工事例は、最初は3〜5件あれば十分です。「数が少ないから恥ずかしい」と思わなくて大丈夫。1件ずつ、ていねいに載せるほうが伝わります。

ページ構成の考え方は5ページ構成の記事にもまとめています。

写真は「現場・完成・人」の3種類

建設業のホームページで、文章より大事なのが写真です。撮るのは3種類だけ覚えてください。

  • 現場の写真：作業中の様子。整理整頓された現場は、それだけで信用になります。
  • 完成の写真：引き渡し前の、きれいな状態。できれば昼間の自然光で。
  • 人の写真：職人さん、スタッフ、代表の顔。笑っていなくても、まっすぐ立っているだけでいい。

スマホで十分です。コツは「横向きで撮る」「逆光を避ける」「余計なものを片づけてから撮る」の3つ。くわしくはスマホ写真の記事をどうぞ。

施主さんの家を載せるときは、必ず本人に許可をもらいましょう。表札や住所が分かるものは写さないのが基本です。

採用への効果：求人票では伝わらないことを伝える

建設業で「人が来ない」と悩む会社は多いです。求人を出しても反応がない。来ても、すぐ辞める。

原因のひとつは、求人票だけでは職場の雰囲気が分からないことです。応募する人は、求人票を見たあと、必ず社名で検索します。そこにホームページがあって、現場の写真と先輩の顔が見えると、「ここなら大丈夫そう」と思ってもらえます。

採用ページには、こんなことを書いてみてください。

  • 1日の流れ（朝何時に集合して、何時に終わるか）
  • 未経験でも大丈夫か、どう教えるか
  • 休みの取り方、繁忙期と閑散期
  • 先輩のひとこと（「入って3年、今は○○を任されています」など）

求人サイトに書けないことを、自分のホームページには自由に書けます。採用の考え方は採用とホームページの記事でもくわしく触れています。
