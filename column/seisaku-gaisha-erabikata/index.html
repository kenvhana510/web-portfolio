ホームページ制作会社を選ぶとき、いちばん大事なのは「見積もりをもらう前に、7つの質問をする」ことです。総額、含まれるもの、納期、修正回数、公開後の更新、解約と譲渡、実物を見られるか。この7つを聞けば、あとで「こんなはずじゃなかった」がほぼなくなります。この記事では、質問の中身と、相性の見極め方、依頼先のタイプごとの違いを説明します。

結論：デザインより先に「条件」を聞く

多くの人は、制作会社を選ぶとき「デザインがきれいか」から見ます。それも大事です。でも、トラブルになるのはデザインではなく、お金・期間・権利の話がほとんどです。

だから順番は、条件を聞く → 実物を見る → 相性を確かめる。この順で進めると、失敗しにくくなります。

見積もり前に聞くべき7つの質問

メモして、そのまま聞いてください。答えが返ってこなかったり、あいまいだったりしたら、それ自体が判断材料です。

1. 「総額はいくらですか？」

初期費用だけでなく、月額や年額を含めた総額を聞きます。「初期○万円、あとは月○円」と言われたら、自分で何年分かを計算してください。

2. 「その金額に、何が含まれますか？」

ページ数、スマホ対応、サーバー代、SSL、お問い合わせフォーム、写真の用意。含まれるもの・含まれないものを、紙で出してもらうのがいちばん確実です。

3. 「納期はいつですか？」

「素材がそろってから何日」という形で聞きます。あわせて、自分が何を用意すればいいかも聞いておきましょう。写真と文章が遅れると、納期も遅れます。

4. 「修正は何回までできますか？」

制作中の修正回数に上限があるのか、超えたらいくらか。ここが決まっていないと、「もう1回直して」が言いにくくなります。

5. 「公開したあとの更新は、誰が、いくらでやりますか？」

ホームページは公開してからが長いです。自分で更新できる仕組みか、頼むなら1回いくらか、月額に含まれるか。ここが決まっていないと、サイトはすぐに古くなります。

6. 「解約したら、サイトはどうなりますか？」

やめたときにサイトが消えるのか、データとドメインを引き継げるのか。所有権の話です。契約書に書いてあるかも確認してください。

7. 「実物を見せてもらえますか？」

デザインのサンプル画像ではなく、実際に動いているサイトを見せてもらいます。スマホで開いて、ボタンを押して、フォームを見てみる。それでだいたい分かります。

ポイント 7つ全部に、はっきり答えが返ってくる会社なら、大きなトラブルはまず起きません。あいまいな答えが多いほど、あとで困る可能性が高くなります。

相性を見極める2つのサイン

条件がそろっていても、「なんか話しにくい」会社だと、長く続きません。相性は、次の2つで見えてきます。

返信の速さ

問い合わせへの返事が、1〜2営業日で来るか。これは制作が始まってからの対応スピードとだいたい同じです。最初に遅い会社が、あとから速くなることはほぼありません。

専門用語を使わずに説明してくれるか

「ドメイン」「サーバー」「CMS」と言われて、分からないまま進めてしまうと、あとで必ず困ります。こちらが分かる言葉で言い直してくれるか。これは、お客さんの立場で考えてくれるかどうかの、いちばん分かりやすいサインです。

大手・フリーランス・サブスク型の違い

依頼先は、大きく3タイプあります。どれが良い悪いではなく、向いている人が違います。

タイプ向いている人気をつける点
大手の制作会社大きなサイト、複雑な機能がほしい費用は高めになりやすい。担当が変わることも
フリーランス細かく相談しながら作りたい連絡が取れなくなるリスクを確認。公開後の体制も
サブスク型（月額）初期費用を抑えて、更新しながら使いたい契約期間・総額・解約時の扱いを必ず確認

小さな会社やお店なら、5ページくらいのサイトを、更新しながら長く使う形がほとんどです。その場合、フリーランスかサブスク型が候補になりやすいです。

費用の相場感は、制作費用の相場の記事と月額費用の相場の記事で、幅を持たせて書いています。

うちの場合、7つの質問にこう答えます

参考までに、LEGACRAFTに同じ質問をしたときの答えを書いておきます。

  1. 総額：制作費0円、月額2,980円（税込）、24ヶ月契約で総額71,520円
  2. 含まれるもの：5ページ程度の制作、スマホ対応、WordPress、サーバー費用・常時SSL、お問い合わせフォーム、Googleマップ・SNSリンク、基本SEO設定、LINEサポート。実費はドメイン代（年額）のみ
  3. 納期：素材がそろってから14日間
  4. 修正回数：制作中も公開後も回数無制限
  5. 公開後の更新：月額に含まれ、追加料金なし。WordPressなので自分でも更新できる
  6. 解約・譲渡：途中解約は原則不可。24ヶ月たったらサイト一式を完全譲渡。希望すれば同じ月額で保守継続も可
  7. 実物：制作例を6件公開中（架空企業を想定した自主制作サンプルです）

EC・予約システム・多言語など大きな機能は、別途見積もりです。細かい点はよくある質問と制作の流れにまとめています。

契約前に、もうひとつだけ

最後に、どの会社に頼むとしても守ってほしいことがあります。

口頭の説明だけで決めず、契約書か申込内容を文字で残す。 「言った・言わない」は、一番つらいトラブルです。LINEやメールのやり取りを残しておくだけでも、ずいぶん違います。
