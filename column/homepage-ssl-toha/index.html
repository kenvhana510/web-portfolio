ホームページのSSLとは？｜鍵マークの意味と費用をやさしく解説

  6. SSLのよくある勘違いと、今日からできること

SSLとは、ホームページとお客様のあいだのやり取りを守る仕組みです。いまのホームページには、ほぼ必須と考えてください。SSLが無いと、ブラウザに「保護されていない通信」と出て、お客様が不安になります。この記事では、ITが苦手な方にもわかるように、SSLの意味と必要な理由、費用の考え方をまとめます。

SSLとは「手紙を封筒に入れて送る」こと

SSLは、通信を暗号化する仕組みです。暗号化とは、ほかの人に中身を読まれないようにすることです。

たとえるなら、ハガキと封筒の違いです。ハガキは、配達の途中でだれでも文面を読めます。封筒に入れれば、中身は受け取った人しか見られません。

SSLが無いホームページはハガキ、SSLがあるホームページは封筒です。お客様が入力した名前や電話番号を、封筒に入れて届けるイメージです。

httpsと鍵マークが目印

SSLが入っているかは、アドレスを見るとわかります。

  • 「https://」で始まる → SSLあり
  • 「http://」で始まる → SSLなし

ブラウザによっては、アドレスの横に鍵マークが出ます。「s」はセキュア（安全）の頭文字、と覚えておけばOKです。

SSLが無いと「保護されていない通信」と出る

SSLが無いホームページを開くと、ブラウザが警告を出すことがあります。「保護されていない通信」「安全ではありません」といった表示です。

お客様はこれを見て、どう思うでしょうか。「このお店、大丈夫かな」と感じて、そっと閉じてしまうかもしれません。

中身がどれだけ良くても、入口で不安を与えたらもったいないです。SSLは、お店の入口をきれいにしておくのと同じです。

古いホームページは要チェック

何年も前に作ったまま、というホームページは要チェックです。当時はSSLが当たり前ではなかったからです。

自分のホームページをスマホで開いて、アドレスを見てみてください。「http://」のままなら、対応を考えるタイミングです。

お問い合わせフォームには特に必要

SSLがいちばん大事になるのは、お問い合わせフォームです。お客様は、名前・電話番号・メールアドレスなどを入力します。

これがハガキのまま送られると、途中で読まれる心配があります。大事な個人情報だからこそ、封筒に入れて届けるべきです。

入力中に「保護されていない」と出たら、送信をためらう人もいます。せっかくの問い合わせを逃さないためにも、SSLは欠かせません。

ポイント：フォームがあるなら、SSLは「あると安心」ではなく「必須」と考えましょう。

うちの場合、常時SSLは月額2,980円（税込）にふくまれています。常時SSLとは、どのページを開いてもhttpsになっている状態のことです。別料金で申し込む必要はありません。

SSLの費用は無料から有料まである

SSLの証明書には、無料のものと有料のものがあります。証明書とは、「このサイトは正しく暗号化しています」という証明書のようなものです。

小さな会社やお店のホームページなら、無料のSSLで足りることが多いです。有料のものには、会社が実在するかまで確認してくれるタイプなどがあります。

費用は、サーバー会社や証明書の種類によって変わります。いまはサーバーの機能として、無料でSSLを使えるところも増えています。

「SSL化の費用」は作業代にも注意

いまあるホームページをSSLに切りかえることを、「SSL化」といいます。証明書が無料でも、切りかえ作業に手間がかかる場合があります。

ページ内の画像やリンクが「http://」のままだと、鍵マークがきちんと出ないことがあります。自分でやるのが不安なら、制作会社に相談しましょう。

SSLで確認したい4つのこと

SSLを入れるとき、またはホームページを頼むときは、次の点を確認しましょう。

  1. 全ページがhttpsで開けるか（常時SSLか）
  2. 「http://」で開いても、自動でhttpsに切りかわるか
  3. 証明書の更新を、だれが管理してくれるか
  4. 費用は月額込みか、別料金か

証明書には有効期限があります。更新がもれると、警告が出てしまいます。自動で更新されるか、管理してくれる人がいるかを確かめておくと安心です。

SSLのよくある勘違いと、今日からできること

勘違い1：SSLがあれば何でも安全

SSLが守るのは、お客様とホームページのあいだの「通信」です。パスワードの使い回しや、古いままの仕組みまで守ってくれるわけではありません。WordPressなどを使っている場合は、更新もあわせて続けることが大切です。

勘違い2：フォームが無いならいらない

お問い合わせフォームが無くても、SSLが無いと警告は出ます。お客様からは、フォームがあるかどうかは関係なく「安全ではないサイト」に見えてしまいます。会社案内だけのホームページでも、SSLは入れておきましょう。

勘違い3：一度入れたらずっと放っておいていい

先ほどのとおり、証明書には期限があります。ある日とつぜん警告が出た、という場合は、更新もれをうたがってみてください。

今日からできること

  1. スマホとパソコンで、自分のホームページを開く
  2. アドレスが「https://」か、鍵マークが出ているかを見る
  3. お問い合わせページも同じように確認する
  4. 「保護されていない」と出たら、制作会社やサーバー会社に連絡する

5分あればできる確認です。まずは自分の目で見てみましょう。

あわせてホームページのサーバーとはや独自ドメインの選び方も読んでおくと、全体の仕組みがつかめます。

まとめ

  • SSLは、お客様とのやり取りを「封筒に入れて」守る仕組み
  • 「https://」と鍵マークが、SSLありの目印
  • SSLが無いと「保護されていない通信」と出て、お客様が不安になる
  • お問い合わせフォームがあるなら、SSLは必須
  • 費用は無料から有料まで。更新の管理もふくめて確認する
